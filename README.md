# Digi24 📷

## معرفی پروژه

**Digi24** یک وب‌سایت فروشگاه اینترنتی برای فروش دوربین و تجهیزات عکاسی است که با استفاده از **PHP، MySQL، HTML، CSS، Bootstrap و JavaScript** توسعه داده شده است.

این پروژه شامل بخش‌های مختلفی برای کاربران و مدیر سایت است و هدف آن ایجاد یک فروشگاه اینترنتی کامل و کاربردی برای محصولات حوزه عکاسی است.

## امکانات پروژه

### 👤 بخش کاربر

- ثبت‌نام و ورود کاربران
- حساب کاربری
- مشاهده محصولات
- مشاهده جزئیات محصولات
- افزودن محصولات به سبد خرید
- مدیریت سبد خرید
- افزودن محصولات به علاقه‌مندی‌ها
- انتخاب گارانتی و روش ارسال
- ثبت و مشاهده نظرات
- بخش پرسش و پاسخ
- مشاهده مقالات

### 🛠️ پنل مدیریت

- مدیریت محصولات
- افزودن، ویرایش و حذف محصولات
- مدیریت مشخصات محصولات
- مدیریت نظرات
- مدیریت مقالات
- مدیریت کاربران
- مدیریت بخش‌های مختلف فروشگاه

## تکنولوژی‌های استفاده‌شده

- **PHP**
- **MySQL**
- **HTML5**
- **CSS3**
- **JavaScript**
- **Bootstrap 5**
- **XAMPP**
