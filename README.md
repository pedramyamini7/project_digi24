# Digi24 📷

## معرفی پروژه

**Digi24** یک وب‌سایت فروشگاه اینترنتی برای فروش دوربین و تجهیزات عکاسی است که با استفاده از **PHP، MySQL، HTML، CSS، Bootstrap و JavaScript** توسعه داده شده است.

این پروژه شامل بخش‌های مختلفی برای کاربران و مدیر سایت است و هدف آن ایجاد یک فروشگاه اینترنتی کامل و کاربردی برای محصولات حوزه عکاسی است.

## امکانات پروژه

### 👤 بخش کاربر

- مدیریت سبد خرید
- افزودن محصولات به علاقه‌مندی‌ها

- مدیریت مشخصات محصولات
- مدیریت مقالات
- مدیریت کاربران
- مدیریت بخش‌های مختلف فروشگاه

## پایگاه داده

پروژه از **MySQL** برای ذخیره اطلاعات کاربران، محصولات، مشخصات محصولات، نظرات، مقالات و سایر اطلاعات فروشگاه استفاده می‌کند.

## اجرای پروژه

برای اجرای پروژه به صورت محلی:

1. نرم‌افزار **XAMPP** را نصب کنید.
2. Apache و MySQL را اجرا کنید.
3. پوشه پروژه را داخل پوشه `htdocs` قرار دهید.
4. پایگاه داده پروژه را در phpMyAdmin ایجاد و Import کنید.
5. تنظیمات اتصال به دیتابیس را در فایل تنظیمات پروژه وارد کنید.
6. پروژه را از طریق مرورگر اجرا کنید.
7. در مرورگر این پیوند رو سرچ کنید.
8. http://localhost/project%20-php/
