1. وارد phpMyAdmin شوید.
2. یک دیتابیس جدید با نام  pedramm_digi_24 ایجاد کنید.
3. فایل `database/digi24.sql` را Import کنید.
4. تنظیمات اتصال به دیتابیس را در فایل تنظیمات پروژه وارد کنید.
5. پروژه را اجرا کنید.
